# Resource Journal

请帮我搭建一个资源查找网页，要求是可以像记笔记一样将我更新的资源链接展示在网页中，可以通过下滑查看笔记中添加的所有资源，也可以通过搜索查找定位相应的资源；页面顶部样式参考图片所示，下方的资源展示界面不需要复杂的模块和格式，就类似金山文档一样的笔记界面，可以以markdown或富文本的格式往上不断添加内容，每次添加的内容不需要划分版块和区域，都在同一个块里编辑，可以像编辑文档一样在这个区域里任意位置添加或修改内容，所有内容像图二一样，从上往下展示即可，要求能够自动识别我粘贴的链接、图片等；前端显示的所有内容都可以在后台自定义设置，包括网页名称、网页logo、副标题等，并且保证当我自定义设置后，打开网页就永远不再显示默认样式，自动显示我自定义设置的样式
